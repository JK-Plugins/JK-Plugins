# JK Fill Erase

指定した点から、ペイントソフトの塗りつぶし（バケツ）ツールと同じように
「似た色でつながっている範囲」を求めて、その範囲を透明にする After Effects プラグインです。
セル画の背景色だけ抜く・塗りの一部だけ消す、といった使い方を想定しています。

**ブラウザで試す：https://jk-plugins.github.io/JK-Plugins/try/fillerase/**

## 仕組み

1. 点の位置のピクセルの色を基準にする
2. 基準の色との差（R・G・B・A それぞれの差の一番大きいもの）が Tolerance 以下のピクセルを、
   上下左右（4近傍）につながっている範囲だけ広げる。斜めには進まないので、1px の線のすき間からは漏れにくい
3. その範囲のアルファを 0 にする（色はそのまま）

点は Point Count で 1〜99 個まで増やせます。それぞれの点から求めた範囲を合わせて消します。
4. Choke で消す範囲のふちを広げたり縮めたりする（距離変換で測るので、値を大きくしても重くなりにくい）

## パラメータ

| 名前 | 内容 |
|---|---|
| Point Count | 使う点の数（1〜99、初期値 1）。数より後ろの点はエフェクトコントロールから隠れる（値は残る） |
| Point 1〜99 | 塗りつぶしの起点。コンポジションパネルで動かせる。レイヤーの外にある点は無視する |
| Tolerance | 同じ色とみなす差（0〜100%）。大きいほど広く消える |
| Softness | Tolerance を超えてからこの幅で、だんだん薄く消す（0% でくっきり）。アンチエイリアスのふちをなめらかにしたいときに |
| Choke | 消す範囲のふちを動かす（px）。プラス：外側に広げる（線画のふちに残る中間色まで消す）。マイナス：内側に縮める（線のきわに塗りを少し残す）。ふちは 1px でなめらかにする |
| Contiguous | オン（初期値）：点とつながっている範囲だけ消す。オフ：画像全体の似た色を全部消す |
| Compare Alpha | オン（初期値）：アルファも比べる（透明なところと不透明なところを別の色とみなす） |
| Invert | 消す範囲を反転する（塗りつぶした範囲だけを残す） |

## メモ

- 塗りつぶしの範囲は画面の外まで続くことがあるので、要求された範囲に関係なくレイヤー全体を読んでいます（出力は要求された範囲だけ作ります）
- 消す範囲は、入力の画素と設定（Invert 以外）からキーを作ってキャッシュしています。2コマ・3コマ打ちのように同じ絵が続くフレームや、Invert だけ変えたときは塗りつぶしをやり直しません
- 入力を float の画像に変換せず、塗りつぶしで調べる画素だけをバイト列から読みます
- 1/2 画質などの縮小表示でも、点の位置と Choke の幅は合わせています
- AE ではパラメータをあとから足せないので、99 個の点を最初から作っておき、使わないものを隠しています
- 8 / 16 / 32bit に対応しています
- CPU だけで処理します。塗りつぶしは隣へ順に広げる処理で GPU に向かず、画像を GPU に送って戻すだけで CPU の処理全体より時間がかかるため（HD で全体 5〜25ms 程度、`cargo run --release -p fillerase --example bench` で測れます）

## ビルド

```bash
cd fillerase
cargo jk install
```
